Release notes

Every Canvasmith release, newest first. The project started at 1.0.0; each minor version groups a milestone of features, and patch versions are fixes and polish.

Unreleased

In progresson branch bug_fixes_and_ux_enhancement

Offline background removal with touch-ups, and this documentation.

Added

  • Offline Remove BG. A new worker pipeline (cutout / cutRefine) cuts the subject out without any AI key: a plain backdrop is keyed out by colour, anything else is auto-seeded and refined with GrabCut along the edge, with soft, colour-decontaminated edges. The result is still a layer mask.
  • Keep / Remove touch-ups for offline cut-outs: paint over what to keep or remove and the cut re-runs around your stroke (setMaskRefine, canRefineCutout).
  • A free offline Remove BG button stays one click away when an AI key is set.
  • Documentation page (docs/) with screenshots, gestures, worked examples and troubleshooting, and scripts/doc-shots.mjs to regenerate its images from the live demo.
  • This release-notes page.

Improved

  • Browser test coverage for the offline cut-out and refine flow in both the vanilla and React shells.

1.6.0

LatestOctober 5, 2026

Pen tool, right-click menu and border options.

Added

  • Figma-style pen tool with bezier nodes. Click for corners, click-drag for curves, close a path into a filled shape, or end it as an open stroke.
  • Vector edit mode for paths: drag points and handles, add points on a segment, convert smooth ↔ corner, delete points, nudge with the arrow keys. Enter on a selected path opens it.
  • Right-click context menu, shared by both shells: clipboard, arrange, flip, align, select-layer-under-cursor, crop, remove background, masks, and selection actions (copy / cut to new layer, invert, deselect). Failed actions show a toast.
  • Select object on a marquee or lasso: a mask-seeded GrabCut shrinks a rough selection to every object inside it, including inverted and overlapping rings.
  • Border options: solid, dashed or dotted style with dash and gap, inside / centre / outside position, caps and joins, behind a settings button next to Width.
  • Eye toggles to hide and show a layer's fill and border independently, without losing either.
  • A busy spinner at the pointer while computer-vision picks run.

Improved

  • Two-tone selection outline (deep blue over a white halo) and a themed multi-selection that read clearly on any artwork.
  • Expanded keyboard handling for the pen build and vector edit modes (⌫, ⌘Z per point, arrows, ⌘A).
  • Layer-mask engine extended, and the editor's browser tests grew to cover the new tools in both shells.

1.5.0

October 1, 2026

A redesigned right panel, AI Assist, and photo-grade adjustments.

Added

  • Right-panel redesign with underline tabs: Properties, Design, Stickers and AI Assist. New Canvas dimensions section with ratio shortcuts, and a background fill with hex, opacity and a Transparent option (drawn as a checkerboard).
  • AI Assist: describe a change scoped to a selection or the whole canvas, style presets, an optional reference image, Enhance prompt, Remove selection (erase and fill) and background swap.
  • Remove BG as a non-destructive layer mask, using the AI when a key is set or a GrabCut cut-out otherwise, plus Auto Shadow.
  • Photo adjustments (tone.js): exposure, highlights, shadows, temperature, tint, vibrance, tone curves (RGB + per channel, with presets), an HSL colour mixer and a live luminance histogram.
  • Geometry (geometry.js): straighten, vertical and horizontal keystone, and a four-corner perspective editor.
  • Nested groups in the Layers panel with arbitrary depth, fold / unfold, drag-reorder across levels, and double-click to drill into a group, one level per double-click.
  • Guided Convert to layers: a full review panel (regions.js) with live outlines and a hover preview before layers are created.
  • Corner radius control for shapes, and resizable, auto-trimmed paint layers.
  • Three new ways to use Canvasmith: a Claude Desktop extension (.mcpb MCP App), a Gemini CLI extension, and a ChatGPT app (a remote MCP server with export links).

Improved

  • Gemini provider hardened, with more of the editor's AI actions routed through the provider registry.
  • PNG / JPEG export and project serialisation updated for the new layer types.
  • The React shell kept in step with the vanilla demo across the whole redesign.

1.4.0

September 16 – 22, 2026

Autosave, project files and a round of painting-tool polish.

Added

  • Session autosave and restore (session.js), shared by both shells. Your document survives a reload; when browser storage is tight, the heaviest data is shed first instead of failing.
  • Recoverable New: the previous document goes to a restorable trash rather than being destroyed, backed by Editor#reset().
  • .canvasmith project files: export and re-open a document with every layer, mask and adjustment intact.
  • Export size of 1×, 2× or 3×, with the output dimensions shown in the menu.

Improved

  • Painting: a choice between painting on the image itself or on a new layer, a live brush cursor ring, and a clone-stamp status with a reset-source button.
  • Gradient tool: handles stay on screen so a gradient can be re-aimed after it is drawn.
  • Crop and selection tools: smoother handles, restoring the correct crop target, and several selection fixes.
  • Zoom-to-placement: the view now follows where new content is placed.
  • Updates to the CV worker behind object picks, and an undo history that can be re-baselined after a restore so one undo never wipes a restored document.
  • JPEG export flattens transparency onto white instead of black.

1.3.0

September 11 – 14, 2026

Stickers, ad copy and Convert to layers.

Added

  • Stickers tab with categorised vector stickers (sale bursts, badges, ribbons, price tags, arrows, accents) that recolour like any shape.
  • Ad copy: ready-made CTA, Badge, Price and Brand lockups, with auto-fit text and legibility shadows (adtext.js).
  • Promo layouts built from templates (templates.js).
  • Background tools: extend the image to fill the artboard, AI-extend any empty canvas around it, and fill with a colour or an image.
  • Convert to layers: detect regions and turn them into editable layers, with object boxes, merged object selections, per-region cut-outs and an animated reveal.
  • Clip a layer to a selection (and clear the clip), and drag-to-reorder layers to any position.
  • Hold Space to pan with any tool, and a select-active-or-centre fallback for object select.

Improved

  • The React shell gained near-complete parity with the vanilla demo, backed by a new Playwright suite for it.
  • AI region detection and the Gemini provider fixed and tightened.

1.2.0

September 6 – 7, 2026

Layer masks, adjustment layers, typography and an offline OpenCV.

Added

  • Layer masks: paintable, non-destructive masks on image and paint layers, with invert.
  • Adjustment layers that apply to everything beneath them in the stack.
  • Typography panel: font (a curated system and Google Fonts list), size, weight, style, alignment and letter spacing.
  • Multi-stop linear and radial gradients, for both the gradient paint tool and vector shape fills.
  • Auto-detect objects tool, wired to the CV engine's detector.
  • Shared keyboard shortcuts (installKeybindings): tool-switch letters and arrow-key nudge, identical in both shells.
  • A real Playwright browser test suite for the DOM-dependent editor code.

Improved

  • OpenCV is now vendored and served locally, so the editor has no runtime dependency on a CDN and the static site works from disk.
  • The React Properties panel brought to parity with the demo's.

Fixed

  • A brush at hardness 1 painted nothing at all.
  • The paint gradient tool never fired because its drag handler was not wired up.
  • Custom filters (masks, adjustments) could silently do nothing under WebGL; Canvas2D filtering is now forced.
  • Rapid double-clicks could let an earlier wand pick overwrite a newer selection; stale results are now dropped. Likewise a magnetic-edge map can no longer land after a resize or crop.
  • Deleting the layer you are painting a mask on now tears the mask-edit state down cleanly.

1.1.0

September 1, 2026

OpenCV-powered selections and a Properties panel.

Added

  • OpenCV-backed selection tools running in a Web Worker: object select and hover select with a live preview, falling back to the plain colour-flood wand when CV is unavailable.
  • Properties panel in both the vanilla demo and the React shell for inspecting and editing the selection and the active layer.
  • Image filters and colour utilities: recolour pixels under a selection, gradient-stop helpers, filter specs.
  • Click-drag shape sizing: draw a shape at the size you drag, instead of dropping a default one.
  • Multi-select alignment: align left, right, top, bottom and centre across several layers.
  • Selection pixel helpers shared by fills, gradients and filters (selectionClipObject, renderSelectedPixels).

Fixed

  • Two accidentally committed worktree links broke git clone for other people; they were removed and ignored.

Added

  • Selection and crop overlay rendering in the demo (dashed outline, scrim, thirds guides, handles), as a reference for custom UIs.

1.0.0

August 16, 2026

The first release: a headless image editor on Fabric.js, with a UI, an AI seam and an import bridge.

Added

  • @canvasmith/core: one headless Editor facade with Fabric.js as a peer dependency.
  • Paint engine: brush, pencil, eraser, clone stamp, spot heal, dodge, burn, sponge and red-eye, with selection-clipped strokes.
  • Selections: rectangular and elliptical marquee, lasso and magic wand with contour tracing.
  • Layers: shapes and text, snapshot-based undo and redo, a zoom-aware crop, and export and serialise.
  • AI provider seam: the editor never talks to a model directly. The bundled GeminiProvider runs on the user's own free key, and hosts can register their own server-side provider (see adapters/ditto). With no provider, AI reports itself unavailable and the editor keeps working.
  • Import bridge: ?image=, #img=, postMessage with an acknowledgement, and localStorage; an in-page bookmarklet that works on auth-gated images, and an MV3 browser extension with a right-click menu.
  • @canvasmith/react: a drop-in <CanvasmithEditor/> and a framework-free Canvasmith.mount() standalone bundle.
  • A vanilla demo app that drives the core directly, 12 unit tests over the pure logic, CI on Node 20 and 22, and an MIT licence.
